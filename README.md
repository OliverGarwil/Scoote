# Ritual Agent Explorer

Search and browse Ritual Chain agent deployment rankings.

## Features

- Search agents by address
- View rank, type (persistent/sovereign), and block
- Network statistics
- Recent deployments

## Stack

React + TypeScript + Vite + Tailwind CSS

## Develop

```bash
npm install
npm run dev
```

## Deploy

Build for production:

```bash
npm run build
```

Output in `dist/`.
